# Estética Mirian Prado

Site responsivo em Flask para a Estética Mirian Prado.

## Como executar no PyCharm

1. Abra a pasta `estetica_mirian_prado`.
2. Crie/ative um ambiente virtual.
3. Instale as dependências:

```bash
pip install -r requirements.txt
```

4. Execute:

```bash
python app.py
```

5. Abra no navegador o endereço mostrado pelo Flask, normalmente:
http://127.0.0.1:5000
